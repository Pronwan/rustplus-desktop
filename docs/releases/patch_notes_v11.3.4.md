# 🚀 Rust+ Desktop v11.3.4 Hotfix — Cloud 24/7 Server Matching

Hey @everyone! 🎉

Hotfix **v11.3.4** fixes Cloud 24/7 for servers paired since Rust's November update.

---

### ☁️ Cloud 24/7

* **The right server in the cloud**: Since Rust's November update, a newly paired server no longer reports its address. Cloud 24/7 now tells these servers apart by their Facepunch id, so you no longer see another server's map, and your devices reach the cloud again.
* **No duplicate servers or alerts**: A server you paired again is listed once, joined with its old entry. While the app is open, the cloud steps back as it should, so alerts no longer arrive twice.
* **Existing servers repaired**: Servers that were already mixed up are sorted out on our side. Update the app and open it once, so your devices sync to the right server.

### 💬 Chat Alerts

* **Smart alarm, oil rig and timer alerts are back**: They disappeared from the chat alerts along with Rust's retired events. Oil rig alerts need a smart alarm set up as an oil rig trigger; without one, the entry shows you how.
* **Oil rig crates in the event dock**: With an oil rig trigger set up, the event dock shows your crates again, with a countdown while one is being hacked and when it was last triggered. Setting an alarm as an oil rig trigger now also turns the Logic Engine on.
