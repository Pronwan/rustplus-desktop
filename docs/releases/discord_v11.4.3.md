# 🚀 Rust+ Desktop v11.4.3 — Switch Verification & Builders Sanctuary Fix

Hey @everyone! 🎉

Hotfix **v11.4.3** is out! This update addresses out-of-sync switch states in the device list and updates Builders Sanctuary base imports on the 3D map.

---

### 🔌 Devices & Switches
* **Accurate Switch States**: After clicking a smart switch multiple times, the device list could get out of sync with the game and show the switch ON while it was OFF in-game. The app now verifies the real state after toggling, and Refresh/startup read it correctly.

### 🗺️ 3D Map
* **Builders Sanctuary Relay**: Updated the base import relay to `api.sanc.gg` to ensure creator bases and designs load reliably into the 3D map.
