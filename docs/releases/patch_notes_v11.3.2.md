# 🚀 Rust+ Desktop v11.3.2 Hotfix — Launch-Time Cloud Login Synchronization

Hey @everyone! 🎉

We've rolled out a follow-up hotfix, **v11.3.2**, automatically syncing your current Rust+ login credentials to Cloud 24/7 on launch!

---

### 🌟 Key Highlights & Fixes

#### ☁️ Launch-Time Login Sync
* **Automatic Cloud Update**: The app now automatically syncs your valid local Rust+ login credentials to Cloud 24/7 once per launch (once authenticated with Cloud 24/7 / Offline Integrations consent).
* **Fixes Expired Token Mismatch**: Resolves issues where earlier builds kept stale or expired tokens in the cloud while the desktop app showed valid login, preventing cloud companion socket disconnections.
