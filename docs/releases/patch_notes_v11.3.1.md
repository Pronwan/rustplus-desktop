# 🚀 Rust+ Desktop v11.3.1 Hotfix — Cloud 24/7 Rust+ Login & Server ID Sync

Hey @everyone! 🎉

We've rolled out a follow-up hotfix, **v11.3.1**, fixing Rust+ login renewal and server ID synchronization with Cloud 24/7!

---

### 🌟 Key Highlights & Fixes

#### ☁️ Cloud 24/7 Login & Server Sync
* **Automatic Renewal Sync**: When your Rust+ login automatically renews or when you pair anew, the renewed token now uploads directly to the cloud instead of staying local only.
* **Server ID Resolution**: Server IDs discovered by launch-time backfill are now synced to the cloud, resolving false "login expired" notices and restoring companion socket connectivity while the app is closed.
